# ADR 004：目標進度取代前端計時器

## 狀態

已採用。

## 決定

「練習」頁面改以「目標進度」呈現，使用者可以建立不限類型的目標，建立時不需要輸入數值欄位，完成後以按鈕標記為「已達成」，也可以恢復為「進行中」。前端不再保存計時器快照，也不提供開始、暫停或清除計時功能。

目標使用 `goals` 與 `goal_progress_logs` 兩張資料表保存。`goals` 保存目前狀態，進度紀錄保存每次狀態更新的日期與備註；資料表中的數值欄位保留作為舊資料與 API 相容，不要求前端使用者輸入。

舊版 `practice_records` 與 `/api/v1/practice` 先保留，讓既有資料匯出、Dashboard 與舊資料移轉不會因頁面改版而遺失。它們不再被新的前端目標頁面使用；未來若要清理資料，必須另行備份與規劃 migration。

## 理由

- 目標可以涵蓋學習、工作、健康、創作與生活，不被鋼琴或單一活動限制。
- 手動進度比背景計時更容易理解，也不會因瀏覽器分頁、睡眠或裝置切換產生錯誤時間。
- 保留舊資料但移除舊 UI，可以兼顧使用者需求與資料可回復性。
